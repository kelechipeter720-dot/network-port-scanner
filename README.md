
# Network Port Scanner

A Python-based network port scanner built with Streamlit.

## Live Demo
[Open Network Port Scanner](https://network-port-scanner-56eet3qujxwjkabdnqt9yv.streamlit.app/)

## Features
- Simple web-based interface
- Checks connectivity on selected ports
- Identifies common services (SSH, HTTP, HTTPS, FTP, DNS)
- Displays scan results and summary metrics

## Technologies Used
- Python
- Streamlit
- Socket Programming

## Purpose
Created as a hands-on Python networking and cybersecurity learning project. Intended for use on systems where scanning is authorized.
